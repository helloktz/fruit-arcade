# 跑燈玩法
九鍵由左至右為蘋果 5、西瓜 20、雙星 30、777 40、BAR 100、雙鈴 20、藍果 15、橘子 10、櫻桃 2。每鍵可押 0 至 100 分。開始時扣除總押注，普通燈按該鍵押注乘以倍率派彩；兩個側 BAR 分別按 50、25 倍計。
列車響笛兩次，沿前方連送 2 至 6 燈。全燈獎依序點亮 28 格，每種圖案只計一次，以面板倍率乘該鍵押注再加倍。特殊燈只在主跑燈停下時觸發。
命運及機會依權重選出一項獎勵。三轉輪三同按總押注乘轉輪倍率派彩，依序出現蘋果、橘子、櫻桃時追加小瑪莉。小瑪莉隨機點三格，按總押注乘該格倍率。送燈隨機點 1、2、3、6 或 28 格。九蓮寶燈隨機點九格，大三元及大四喜各有固定燈組，均按各格的實際押注派彩。
得分可直接領取或猜大小。1–6 為小，8–13 為大，7 為和局。猜中翻倍，猜錯歸零，最多五次，分池上限一百萬。
