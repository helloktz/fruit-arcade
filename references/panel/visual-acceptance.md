# 复古灯箱美术验收

这套方法适用于一份低像素原图和一套可替换的 SVG 素材。每个图案先核对能从资料确认的形状，再在游戏实际尺寸下检查。整机复查时，分别看背板印刷、灯格、数码窗和亮灯演出。

含参考照片的叠图和分格对照链接用于本地档案。公开版本可直接查看测量数据、终稿 SVG 及原创机台截图。重新生成对照图之前，按[参考裁图库](README.md)准备本地照片和裁图。

## 怎样验收一个图案

1. **固定参照和状态。** 先从 [裁图索引](index.csv) 取同一格的两份照片。用露天正面照核对格序、字和几何，用实机照核对另一拍摄角度下仍能看见的特征。再找同图案的重复灯格及对应押注键，记录反光、亮灯、遮挡和色偏。实机照 `L26` 已点亮，所以以露天照判断「命運」的字形和绿色油墨。
2. **先看剪影和排列。** 在原始像素上记下部件数量、遮挡顺序、朝向、中心距、左右或上下关系、图案占灯格的比例。能分割的色块可以分别拟合，例如用西瓜红色切面的质心、椭圆长轴和宽高比。改变分割阈值重复量一次，记录稳定的量和随阈值变化的量。用叠图检查分割选中了哪一部分，再选择 SVG 的几何约束。
3. **把确认的几何做进结构。** 外轮廓由连续的贝塞尔曲线拟合。相同形体用 `<use>` 实例化。需要对称的部分由反射变换复用。真实的边缘起伏单独写进相应路径，例如瓜纹的疏密和错落。轮廓、主色、纹路、阴影和高光分层，通过根层色板换色。照片里随拍摄条件变化的散点和锯齿只作为判读线索。以西瓜为例，照片能支持深浅层次，不能定位独立瓜籽，图中用纵向扩散的深红表现瓜肉。
4. **同一张对照里看两个尺度。** 照片用最近邻放大，保留原始像素边界。成品放入实际页面，灯格从浏览器截图逐格取样，无放大，只允许像素边界取整。然后从 SVG 直接大尺寸渲染，再看路径连接、裁切、尖角和内部留白。不要用放大截图判断矢量边缘。在原尺寸下须先认出是谁，再检查部件数量、倍率和文字；在大图上须能解释每条边来自哪段轮廓、哪层纹路或哪块光影。
5. **在机台上复核。** 相同图案需要在灯格、押注键和转轮中辨认成同一项。检查亮灯后红果、倍率和字仍有足够的明暗区分。先看 1280 × 900 的桌面窗口，再看 390 × 844 的手机视口。此轮在 Edge、设备像素比 1 下，灯格分别是 **42.8 × 43.7** 和 **27.6 × 28.2 CSS px**。浏览器另测试了 320 像素窄屏和 844 × 390 横屏。

剪影、数量、朝向、格序、倍率或印字错误时，先修这些项目。相邻色块在原尺寸连成一片时，优先调整间隙和明度，再考虑增加细节。例如放大稿中的星面可见三个明度层，手机视图需要保住的是两颗可区分的五角星。每项验收保留能确认的特征、对应图号和样本精度的限制。两份照片的色差、压缩和印刷品批次差异仍在，颜色按同时能观察的相对明暗与冷暖方向判读。

## 整机和运行验证

- **背板。** 在原有果园印刷图层上，用 CSS 渐变把上部压向深蓝，向下过渡为亮青蓝，底端进入较暗的草绿色。下缘花叶仍可看到原有印刷网点。中央保留原创飞行邮差和果园，画面加入低强度的冷色叠印，减少与外缘的色差。
- **灯盘和控制台。** 保留面板 `610:725` 和灯盘 `5:4` 的布局。灯格用冷象牙白到淡蓝，亮态保持黄琥珀色。九键使用同一组冷色底板，倍率与下方暗红分数窗分层。顶部两窗和中央押注窗都用了红色光学层次。
- **特殊状态。** [火車送燈](quality-review/train.png) 截图取在送出的多个灯同亮的阶段，检查灯沿环边相邻排列。[全燈獎](quality-review/grand-slam.png) 截图取在等待领取时，检查 28 格同时亮起及得分窗。[三轉輪](quality-review/reels.png) 在快转模糊结束后取帧，三个转轮均加载押注键使用的同名素材。

从仓库根目录执行下列命令，可重复生成验收图。

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

在另一个终端使用 Edge 执行截图核对。也可以安装 Playwright 自带的 Chromium 并省略 `PW_CHANNEL`。

```powershell
$env:PW_CHANNEL='msedge'
node references/panel/render_review.mjs
python references/panel/watermelon-study/measure.py
npm test
npm run test:e2e
```

截图脚本从 `layout.json` 读取灯位和押注键的参照顺序，检查实际页面 Canvas 的 28 个坐标、九个键的倍率与资源、西瓜复用结构、三转轮素材来源及特殊灯态，并捕获页面异常。奖励样本的随机数由截图脚本注入，棋盘与玩法仍走正式入口。照片、叠图和验收截图均留在参考库，生产页面加载的是原创插图和 SVG。实机色卡、印刷文件、实机测时和音频母带仍缺失，所以这轮验证范围为网页中的图形、布局和演出集成。
